Проект: Разработка и развертывание веб-приложения на FastAPI https://aframe-kam.ru (ссылка уже не работает)

Сайт знакомил пользователей с тремя домами типа A-frame и давал возможность забронировать их через booking.
- Разработал и развернул веб-приложение на VPS сервер.
- Организовал контейнеризацию приложения с помощью Docker, включая настройку Nginx в качестве прокси-сервера и Certbot для обновления SSL сертификата.
- Подключил систему мониторинга на базе Prometheus и Grafana для сбора метрик.
- Добавил Flower для мониторинга задач Celery.
- Frontend был отдан в разработку другому человеку, связывал с Backend-ом я.
- Использовал PostgreSQL + SQLalchemy в качестве основной базы данных, миграции Alembic.
- Интегрировал Telegram-бота на базе aiogram3.
- Redis кэшировал сайт и хранил состоянии бота.
- JWT авторизация.
- Архитектура Unit of Work.
- Тестирование pytest.
В поисковых системах сайт был второй ссылкой при различных вариациях запросов, сразу после объявления на Авито.
